# PRODUCT.md — 产品概述

## 一句话定位

AlgoPlayground 是一个面向计算机初学者的**交互式数据结构与算法可视化学习平台**：把抽象的算法执行过程变成可播放、可暂停、可逐步回看、可对照伪代码理解的"动画教材"。

## 目标用户

- 计算机专业低年级学生、自学编程的初学者
- 准备面试、需要复习算法过程可视化的开发者
- 需要课堂演示工具的教师

## 核心价值

1. **看得见**：每一步比较、交换、入队、递归调用都可视化为明确的图形状态变化。
2. **讲得清**：每个算法配有用途、核心思想、伪代码（随动画高亮当前行）、复杂度与稳定性说明，以及当前步骤的中文解说。
3. **玩得动**：用户可自定义数据、生成随机数据、编辑图结构，用真实交互建立直觉。
4. **比得明**：排序比较模式让最多 3 个算法在同一份数据上同步运行，直观对比步数与比较/交换次数。

## 功能范围（v1.0）

| 模块 | 内容 |
| --- | --- |
| 排序 | 冒泡、选择、插入、归并、快速、堆排序 |
| 搜索 | 线性查找、二分查找 |
| 线性结构 | 栈（Push/Pop/Peek）、队列（Enqueue/Dequeue/Front）、单链表（建表/遍历/插入/删除/查找） |
| 树 | BST 插入/查找/删除；前序/中序/后序/层序遍历 |
| 图 | 可视化编辑器（节点/边/权重/有向无向）+ BFS/DFS/Dijkstra |
| 递归 | 阶乘、斐波那契、汉诺塔（重点展示调用栈） |
| 回溯 | N 皇后（选择/冲突/回退/解） |
| 动态规划 | 斐波那契 DP、0/1 背包（DP 表填充过程） |
| 播放器 | 播放/暂停/上一步/下一步/重播/速度(0.25x~4x)/时间轴拖动/步数显示 |
| 比较模式 | 同一数据最多 3 个排序算法同步对比（Steps/Comparisons/Swaps/复杂度） |
| 教学模式 | 每个算法页含名称/用途/核心思想/伪代码/复杂度/稳定性/当前步骤解释 |
| 主题 | Dark Mode 默认，Light 可切换；桌面与普通浏览器自适应 |

## 非目标（v1.0 不做）

- 不做账号系统、云同步、社区功能
- 不做移动端 App（仅保证普通浏览器与桌面可用）
- 不做代码编辑器式自定义算法执行
- 不追求复杂视觉特效，可读性优先
- 不支持无向带权最短路以外的最短路变体（如 Bellman-Ford/Floyd，留给 v1.1）

## 成功标准

- 全部算法通过自动化正确性测试（边界 + 随机数据对照标准实现）
- 播放器支持任意回退/拖动且结果可重放（步骤为预计算快照）
- `lint / typecheck / test / build` 四项全绿
- 初学者无需文档即可理解主界面（左侧分类 → 中间动画 → 右侧讲解 → 底部播放器）
