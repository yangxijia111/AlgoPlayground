# PRIVACY.md — 隐私说明（v1.1.0）

**AlgoPlayground 不收集任何数据。**

## 我们收集什么？

什么都不收集。具体而言：

- ❌ 无账号系统——不需要注册、登录，也没有任何身份信息。
- ❌ 无后端服务器——应用是纯静态页面，部署在 GitHub Pages 上。
- ❌ 无遥测、无埋点、无统计分析脚本。
- ❌ 无学习数据上传——你的学习进度、Quiz 答题记录、预测记录、挑战成绩、笔记、收藏、保存的图预设，全部只保存在**你自己浏览器的 localStorage** 中，永不离开你的设备。

## 网络请求

应用唯一的网络行为是**从 GitHub Pages 加载页面本身**（HTML/CSS/JS 静态资源）。加载完成后，应用运行期间**不发出任何网络请求**。不加载任何第三方统计、广告或字体服务。

## 本地存储了什么？

| 键 | 内容 |
| --- | --- |
| `algoplayground-learning` | 学习数据（进度/答题/预测/挑战/笔记/收藏/图预设/设置），版本化 JSON |
| `algoplayground-theme` | 主题偏好（dark/light） |

你可以随时在「进度 → 数据管理」中导出（JSON 文件）、导入或一键重置学习数据；重置只删除上面两个 AlgoPlayground 自己的键，绝不触碰同域下其他应用的数据。

## 分享链接

「分享」功能生成的 URL 只包含**算法的公开输入数据**（如数组内容、图结构），绝不包含你的笔记、进度、历史记录或任何个人信息。
